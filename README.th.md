# ส่วนขยาย ChronoArchive สำหรับ VS Code

**ภาษา:** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Tiếng Việt](README.vi.md) · **ไทย**

รองรับภาษาสำหรับไฟล์ chronoarchive (`.car`) — รูปแบบข้อความธรรมดาที่มีโครงสร้างสำหรับติดตามงาน บันทึกเวลา และคอนเทนเนอร์พรอมต์

ส่วนติดต่อของส่วนขยาย (คำสั่ง การตั้งค่า คำอธิบายโทเค็นเชิงความหมาย) แปลผ่าน `package.nls.json` และ `package.nls.<locale>.json` VS Code ใช้ภาษาที่แสดง (`Configure Display Language`) โลเคลใน repo: `en` (ค่าเริ่มต้น `package.nls.json`), `zh-cn`, `zh-tw`, `ja`, `ko`, `vi`, `th`

## คุณสมบัติ

- **ไฮไลต์ไวยากรณ์**: ไวยากรณ์ TextMate ครบ
- **โทเค็นเชิงความหมาย**: เน้นธง วันที่-เวลา ตัวดัดแปลง และแอตทริบิวต์
- **พับโค้ด**: พับแต่ละรายการและบล็อกซูเปอร์เฮดเดอร์
- **การวินิจฉัย**: ตรวจเวลาหาย เพย์โหลดว่าง รายการผิดรูปแบบ
- **สัญลักษณ์เอกสาร**: มุมมองเค้าโครงแสดงรายการทั้งหมด
- **CodeLens**: การทำงานด่วนสำหรับรายการ `/prompt`
- **แป้นพิมพ์ลัด**: วนธง นำทาง และจัดการรายการ
- **การย้ายอัจฉริยะ**: คงตำแหน่งเคอร์เซอร์เมื่อย้ายรายการ
- **ปรับแต่งอัตโนมัติ**: จัดการบรรทัดว่างระหว่างรายการ

## การติดตั้ง

1. โคลนที่เก็บ  
2. รัน `npm install`  
3. กด F5 เพื่อเปิด Extension Development Host  
4. เปิดไฟล์ `.car`

## การใช้งาน

สร้างไฟล์ `.car` แล้วเขียนรายการแบบมีโครงสร้าง

**บันทึกรายวัน:** กด **Ctrl+Alt+D** (หรือ **Alt+Meta+D**) เพื่อสร้างและเปิดบันทึกวันนี้ เส้นทาง `<root>/ปี/ปี-เดือน/ปี-เดือน-วัน.car` หากมีไฟล์อยู่แล้วจะเปิด มิฉะนั้นสร้างจากเทมเพลต ใน**การตั้งค่า** → **ChronoArchive** ตั้ง **Daily Logs Root** (เว้นว่าง = ค่าเริ่มต้น: Linux `~/Documents/Daily Logs` หรือ `$XDG_DOCUMENTS_DIR/Daily Logs`; Windows `%USERPROFILE%\Documents\Daily Logs`) และ **Daily Log Template Path** (ตัวยึด `{{CREATION}}`, `{{TIME}}`; เว้นว่างใช้เทมเพลตในตัว)

## แป้นพิมพ์ลัด

(ปุ่มลัดเหมือนใน README ภาษาอังกฤษ)

### วนธง

| แป้นพิมพ์ลัด | ลำดับธง | คำอธิบาย |
|----------|------------|-------------|
| `Ctrl+/` | ☑️ → ✅ → 🎉 → ปิด | เสร็จสิ้น |
| `Ctrl+'` | ❌ → ❎ → 🗑️ → ปิด | ปิด |
| `Ctrl+Shift+/` | 🟡 → ⏱️ → ⌛ → 🚧 → 🔄 → 🛠️ → ปิด | รอดำเนินการ |
| `Ctrl+Shift+\` | 📝 → 📍 → 📌 → ปิด | ความสำคัญ |
| `Ctrl+Shift+'` | ⚠️ → ‼️ → 🔥 → ปิด | ความสนใจ |
| `Ctrl+@` | ☕️ → 🍵 → 🍼 → 🍻 → 🍹 → 🍷 → ปิด | เครื่องดื่ม |
| `Ctrl+)` | 💕 → 🤏 → ☺️ → 😃 → 👍 → 😍 → 😘 → ปิด | อารมณ์ดี |
| `Ctrl+(` | 🥺 → 🫩 → 😂 → 🤣 → 😭 → 😅 → 💀 → ปิด | อารมณ์ไม่ดี |

### บันทึกรายวัน

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `Ctrl+Alt+D` | สร้างและเปิดบันทึกวันนี้ |
| `Alt+PageUp` / `Alt+PageDown` | ไปยังบันทึกวันที่มีอยู่ใกล้ที่สุด (ไม่สร้างไฟล์) |
| `Ctrl+Alt+PageUp` / `Ctrl+Alt+PageDown` | เปิดบันทึกวันก่อน/ถัดไปตามปฏิทิน (สร้างจากเทมเพลตถ้าไม่มี) |

### ความสำคัญ

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `Ctrl+1` ~ `Ctrl+5` | ตั้งความสำคัญ 1–5 ดาว ⭐ |

### นำทางรายการ

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `Ctrl+K` | รายการก่อนหน้า |
| `Ctrl+J` | รายการถัดไป |
| `Alt+K` | ย้ายรายการขึ้น |
| `Alt+J` | ย้ายรายการลง |

### เพิ่มรายการ

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `Alt+]` | เพิ่มหลังตำแหน่งปัจจุบัน |
| `Alt+[` | เพิ่มก่อนรายการปัจจุบัน |
| `Alt+Shift+[` | เพิ่มก่อนบรรทัดปัจจุบัน |
| `Ctrl+Alt+=` | เพิ่มท้ายไฟล์ |

### ลบ

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `Alt+Delete` | ลบรายการปัจจุบัน |

### การตั้งค่า

| การตั้งค่า | ค่าเริ่มต้น | คำอธิบาย |
|---------|---------|-------------|
| `chronoarchive.blankLinesBetweenItems` | `0` | จำนวนบรรทัดว่างระหว่างรายการ (0–3) |

### โครงสร้างรายการ

1. **แถวหัว** (จำเป็น): `[ธง] [วันที่] เวลา [ตัวดัดแปลง]`
2. **แอตทริบิวต์** (เลือกได้): คู่ `ชื่อ: ค่า` เยื้อง
3. **เพย์โหลด** (จำเป็น): บล็อกเนื้อหาเยื้อง

### ตัวดัดแปลง

- `/prompt` — ทำเครื่องหมายว่าเป็นพรอมต์
- `/php`, `/python`, `/json` ฯลฯ — คำใบ้ภาษา
- `/lang=identifier` — ระบุภาษาโดยชัดเจน
